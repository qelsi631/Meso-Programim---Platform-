CSS Box Model: Si funksionon kutia e çdo elementi

Çdo element HTML është si një kuti. Kjo kuti ka 4 shtresa: Content (përmbajtja), Padding (mbushja), Border (kufiri), dhe Margin (hapësira e jashtme). Kjo quhet Box Model.

Kuptimi i Box Model është thelbësor për pozicionimin dhe madhësinë e elementeve në faqe.

Rendi nga brenda drejt jashtë:

Content → Padding → Border → Margin
Mendo sikur kuti e një dhurate: përmbajtja brenda, mbushja (sfungjer), kufiri (kartoni), hapësira jashtë (distanca nga kutitë e tjera).

1. width dhe height — Madhësia e përmbajtjes

Pronat width dhe height caktojnë madhësinë e përmbajtjes (content area).

CSS 
.kutia {
  width: 300px;
  height: 150px;
  background-color: #7c3aed;
}

2. padding — Mbushja e brendshme

Padding krijon hapësirë ndërmjet përmbajtjes dhe kufifit. Shtyn përmbajtjen nga skajet.

CSS 
/* Padding i njëjtë nga të 4 anët */
.kutia-1 {
  padding: 20px;
}

/* Padding i ndryshëm: sipër/poshtë, majtas/djathtas */
.kutia-2 {
  padding: 10px 30px;
}

/* Padding për secilën anë veçmas */
.kutia-3 {
  padding-top: 10px;
  padding-right: 20px;
  padding-bottom: 10px;
  padding-left: 20px;
}
Pa padding vs Me padding
padding: 0
Tekst pa padding
padding: 20px
Tekst me padding
Shorthand (shkurtim)

padding: 10px 20px 10px 20px; → sipër, djathtas, poshtë, majtas (si rrotë e orës).
padding: 10px 20px; → sipër/poshtë 10px, majtas/djathtas 20px.
padding: 20px; → 20px nga të 4 anët.

3. border — Kufiri

Border vizaton një vijë rreth elementit, ndërmjet padding-ut dhe margin-it.

CSS 
/* Shorthand: trashësia stili ngjyra */
.kutia {
  border: 2px solid #7c3aed;
}

/* Stile të ndryshme */
.vize   { border: 2px dashed #ff6600; }
.pika   { border: 3px dotted #22c55e; }
.dyshe  { border: 4px double #3b82f6; }

/* Vetëm njëra anë */
.posht  { border-bottom: 3px solid #ef4444; }
Stilet e kufifit
solid — vijë e plotë
dashed — viza
dotted — pika
double — dyshe
border-bottom — vetëm poshtë

4. border-radius — Cepat e rrumbullakët

Rrumbullakon cepat e elementit. Vlera më e madhe = më i rrumbullakët.

CSS 
.pak   { border-radius: 4px; }
.mesem { border-radius: 12px; }
.shume { border-radius: 50%; }  /* rreth i plotë */

5. margin — Hapësira e jashtme

Margin krijon hapësirë jashtë kufifit — distancë ndërmjet elementit dhe elementeve përreth. Funksionon njësoj si padding por jashtë.

CSS 
.kutia {
  margin: 20px;            /* 20px nga të 4 anët */
}

.qender {
  width: 300px;
  margin: 0 auto;          /* qendërzim horizontal! */
}

.larg {
  margin-top: 40px;       /* hapësirë vetëm sipër */
  margin-bottom: 40px;    /* hapësirë vetëm poshtë */
}
margin: 0 auto (qendërzim)
Jam në qendër!
margin: auto

margin: 0 auto qendërzon elementin horizontalisht. Kushti: elementi duhet të ketë width të caktuar. Kjo përdoret shumë shpesh në projekte reale!

7. box-sizing — Si llogaritet madhësia

Me parazgjedhje, width cakton vetëm përmbajtjen. Padding dhe border i shtohen sipër! Me box-sizing: border-box, gjithçka futet brenda width-it.

CSS 
/* Rekomandohet — vendose në fillim të CSS */
* {
  box-sizing: border-box;
}
Krahasim
content-box (default) — width: 200px + padding: 20px = 240px total
Kutia del 240px e gjerë!
border-box — width: 200px total (padding përfshihet)
Kutia qëndron 200px!
Best Practice

* { box-sizing: border-box; } përdoret pothuajse në çdo project modern. Kjo e bën llogaritjen e madhësive shumë më të thjeshtë.
