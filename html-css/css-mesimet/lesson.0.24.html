CSS Grid: Bazat e Grid Layout

Kur dëshiron ta ndash faqen në pjesë (header, sidebar, content, footer), CSS Grid është mënyra më e lehtë! Grid të lejon të krijosh rreshta dhe kolona njëkohësisht — si një tabelë, por shumë më fleksibël.

Në këtë mësim do të mësosh bazat: si aktivizohet Grid, si krijohen kolonat dhe rreshtat, si shtohet hapësirë, dhe si ndërtohet një layout i thjeshtë faqesh. Le ta fillojmë! 🚀

1. display: grid — Aktivizo Grid

Hapi i parë është i thjeshtë: vendos display: grid te elementi prind. Kështu fëmijët brenda tij organizohen si grid:

CSS 
.kontejner {
  display: grid;
}

📝 Fjalor i shpejtë

Grid Container = elementi prind me display: grid.
Grid Items = fëmijët direkt brenda kontejnerit.

2. grid-template-columns — Krijon kolona

Me këtë pronë i thua CSS-it sa kolona dëshiron dhe sa të gjera janë:

CSS 
.kontejner {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;
}
/* Krijon 3 kolona të barabarta */
💡 Çfarë është fr?

fr do të thotë "fraction" (pjesë). Ndan hapësirën e lirë në mënyrë të barabartë:
1fr 1fr 1fr → 3 kolona të barabarta
200px 1fr → e para 200px fikse, e dyta merr gjithë hapësirën e mbetur

3. grid-template-rows — Krijon rreshta

Njësoj si kolonat, mund të përcaktosh edhe lartësinë e rreshtave:

CSS 
.kontejner {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;
  grid-template-rows: 60px 120px;
}
/* Rreshti i parë: 60px, i dyti: 120px */

4. repeat() — Shkurtim i dobishëm

Në vend që ti shkruash kolonat një nga një, përdor repeat() për ta shkurtuar:

CSS 
/* Mënyra e gjatë: */
grid-template-columns: 1fr 1fr 1fr;

/* Mënyra e shkurtër (njësoj): */
grid-template-columns: repeat(3, 1fr);
💡 Si lexohet?

repeat(3, 1fr) = "përsërit 3 herë, secila 1fr".
repeat(4, 200px) = "përsërit 4 herë, secila 200px".

6. span — Një element zë disa kolona

Ndonjëherë dëshiron që një element (p.sh. header ose footer) të zë dy ose tri kolona njëherësh. Përdor grid-column: span:

CSS 
.header {
  grid-column: span 3;   /* Zë 3 kolona */
}

.footer {
  grid-column: span 3;   /* Edhe footer zë 3 kolona */
}

span 2 = elementi zë 2 kolona.

Numri varet nga sa kolona ka grid-i yt.

7. grid-template-areas — Layout me emra

Kjo është mënyra më e lehtë për të ndërtuar një layout faqesh! Thjesht i jep emra zonave dhe i vizaton si hartë:

CSS 
.kontejner {
  display: grid;
  grid-template-columns: 200px 1fr;
  grid-template-areas:
    "header  header"
    "sidebar main"
    "footer  footer";
  gap: 10px;
}

/* Çdo element merr emrin e zonës */
.header  { grid-area: header; }
.sidebar { grid-area: sidebar; }
.main    { grid-area: main; }
.footer  { grid-area: footer; }

💡 Si funksionon?

Çdo fjalë brenda thonjëzave është një qelize. Kur emri përsëritet (si "header header"), elementi zë dy kolona! Pastaj çdo element merr grid-area: emri; për tu vendosur atje.

9. Grid vs Flexbox — Kur cilën?

Tani njeh dy sisteme layout: Flexbox dhe Grid. Ja kur ta përdorësh secilën:

Flexbox Grid
Rreshton gjëra në një drejtim (rresht OSE kolonë)Rreshton gjëra në dy drejtime (rresht DHE kolonë)
Ideal për: navbar, butona, karta në rreshtIdeal për: layout faqesh, galeri, dashboard
Më i thjeshtë për gjëra të voglaMë i fuqishëm për struktura të mëdha
💡 Rregulli i thjeshtë

Përdor Flexbox për pjesë të vogla (navbar, butona, lista).
Përdor Grid për strukturën e faqes (header + sidebar + main + footer).
