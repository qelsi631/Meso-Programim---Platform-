Selektorët bazë në CSS

Çfarë është selektori?

Selektori tregon cilin element HTML do të stilizojmë.

Shembuj kryesorë

p {
  color: blue;
}

#titulli {
  font-size: 32px;
}

.karta {
  background: #111;
  color: #fff;
}
  • p = selektor tagu
  • #id = selektor me id
  • .class = selektor me class

Në mësimin tjetër do të punojmë me ngjyrat dhe sfondin.
