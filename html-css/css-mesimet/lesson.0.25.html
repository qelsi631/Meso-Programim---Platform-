Responsive Design: Faqe që përshtaten

A e ke hapur ndonjë faqe në telefon dhe gjithçka ishte shumë e vogël, ose duhej të lëvizje majtas-djathtas? Kjo ndodh kur faqja nuk është responsive.

Responsive Design do të thotë që faqja jote duket mirë në çdo pajisje — kompjuter, tablet, ose telefon. Në këtë mësim do të mësosh si ta bësh këtë me Media Queries! 📱💻

1. Meta Viewport — Hapi i parë

Para se të përdorësh Media Queries, dëshiron ta sigurosh që browseri e di sa i gjerë është ekrani. Kjo bëhet me një tag <meta> në <head>:

HTML 
<meta name="viewport"
      content="width=device-width, initial-scale=1.0">
📝 Çfarë bën kjo?

width=device-width — faqja merr gjerësinë reale të pajisjes (jo 980px të desktop-it).
initial-scale=1.0 — faqja hapet pa zoom (1:1).
Kjo duhet në çdo faqe HTML — pa këtë, CSS responsive nuk funksionon!

2. @media — Rregulli magjik

@media të lejon të shkruash rregulla CSS që aktivizohen vetëm kur kushti plotësohet. Me fjalë të thjeshta: "Nëse ekrani është kaq i gjerë, përdor këtë stil".

CSS 
/* Stili normal (për të gjitha ekranet) */
h1 {
  font-size: 36px;
}

/* Kur ekrani bëhet 768px ose më i ngushtë */
@media (max-width: 768px) {
  h1 {
    font-size: 24px;
  }
}
Si funksionon @media
🖥️ Desktop (> 768px):
Titulli i madh
📱 Mobile (≤ 768px):
Titulli i madh
💡 Si lexohet?

@media (max-width: 768px) = "Kur gjerësia e ekranit është 768px ose më pak".
Stili brenda { } aktivizohet vetëm kur kushti plotësohet!

3. max-width vs min-width

Ka dy mënyra për të shkruar media queries. Ja ndryshimi:

CSS 
/* max-width: Aktivizohet kur ekrani ZVOGËLOHET */
@media (max-width: 768px) {
  /* Stile për tablet dhe mobile */
}

/* min-width: Aktivizohet kur ekrani ZMADHOHET */
@media (min-width: 768px) {
  /* Stile për tablet dhe desktop */
}
Tipi Kuptimi Përdorimi
max-widthkur ekrani ≤ vleraFillo nga desktop, zvogëlo
min-widthkur ekrani ≥ vleraFillo nga mobile, zmadho
💡 Cila është më e përdorshme?

Si fillestare, max-width është më e lehtë: shkruan stilin normal për desktop, pastaj shton @media (max-width: ...) për ta ndryshuar në mobile. Kjo quhet qasja "Desktop First".

4. Breakpoints — Pikat e ndryshimit

Breakpoints janë pikat ku dizajni ndryshon. Ja vlerat më të zakonshme:

Pajisja Gjerësia Media Query
📱 Mobile≤ 480px@media (max-width: 480px)
📱 Mobile i madh≤ 768px@media (max-width: 768px)
💻 Tablet≤ 1024px@media (max-width: 1024px)
🖥️ Desktop> 1024pxStili normal (pa @media)
💡 Këshill

Nuk ka nevojë ti mësosh përmendsh! Vlera më e përdorshme është 768px — kjo mbulon shumicën e tabletëve dhe telefonave. Fillo me këtë!

5. Layout responsive — Grid në 1 kolonë

Shembulli më i zakonshëm: në desktop ke disa kolona, në mobile gjithçka shkon në 1 kolonë:

CSS 
.kontejner {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;
  gap: 16px;
}

@media (max-width: 768px) {
  .kontejner {
    grid-template-columns: 1fr;  /* 1 kolonë */
  }
}

6. Tekst responsive — Font-size

Teksti i madh në desktop mund të mos dukej mirë në telefon. Zvogëloje me @media:

CSS 
h1 {
  font-size: 48px;
}

p {
  font-size: 18px;
}

@media (max-width: 768px) {
  h1 {
    font-size: 28px;
  }
  p {
    font-size: 15px;
  }
}

7. Fsheh elemente në mobile

Ndonjëherë dëshiron ta fshehësh një element në telefon (p.sh. sidebar-in ose një imazh të madh). Përdor display: none brenda @media:

CSS 
.sidebar {
  display: block;
}

@media (max-width: 768px) {
  .sidebar {
    display: none;  /* Fshihet në mobile */
  }
}
Sidebar shfaqet në desktop, fshihet në mobile

8. Shembull — Faqe responsive e plotë

Ja si kombinohen gjithçka në një shembull real:

CSS 
/* Desktop normal */
.faqja {
  display: grid;
  grid-template-columns: 200px 1fr;
  gap: 16px;
}

h1 {  font-size: 36px;  }

/* Tablet ose mobile */
@media (max-width: 768px) {
  .faqja {
    grid-template-columns: 1fr;
  }
  .sidebar {
    display: none;
  }
  h1 {
    font-size: 24px;
  }
}
