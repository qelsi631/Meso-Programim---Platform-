CSS Transitions & Animations: Lëvizje dhe efekte

Deri tani ke mësuar si të stilizosh gjëra — ngjyra, madhësi, pozicion. Por gjithçka ndodh menjëherë. Nuk ka lëvizje, nuk ka efekt.

Me CSS Transitions dhe Animations, mund të shtosh efekte të buta: butona që ndryshojnë ngjyrë ngadalë, elemente që lëvizin, ose gjëra që pulsojnë. Kjo e bën faqen tënde më profesionale! ✨

1. transition — Ndryshim i butë

Pa transition, kur vendos :hover tek një buton, ngjyra ndryshon menjëherë. Me transition, ndryshimi bëhet ngadalë dhe bukur:

CSS 
.butoni {
  background: #7c3aed;
  color: white;
  padding: 12px 24px;
  border: none;
  border-radius: 8px;
  transition: background 0.3s;
}

.butoni:hover {
  background: #5b21b6;
}
Hover mbi butonin — vëzhgo ndryshimin e butë
📝 Si lexohet?

transition: background 0.3s;
= "Kur background ndryshon, bëje ndryshimin brenda 0.3 sekondave".
Pa transition → ndryshon menjëherë. Me transition → ndryshon bukur!

2. Sintaksa e transition

transition ka katër pjesë. Ja çdo njëra:

CSS 
transition: prona  kohëzgjatja  easing  vonesa;

/* Shembuj: */
transition: background 0.3s;
transition: all 0.5s ease;
transition: transform 0.3s ease-in-out;
transition: opacity 0.4s ease 0.2s;
Pjesa Çfarë bën Shembull
propertyCila pronë animohetbackground, color, all
durationSa zgjat ndryshimi0.3s, 0.5s, 1s
easingSi lëviz (e butë, e shpejtë)ease, ease-in-out, linear
delaySa pret para se fillon0s, 0.2s, 1s
💡 Këshill

Përdor all nëse dëshiron të animosh çdo pronë që ndryshon. KJo është mënyra më e thjeshtë: transition: all 0.3s ease;

3. Disa prona njëherësh

Mund të animosh disa prona duke i ndarë me presje:

CSS 
.karta {
  background: white;
  transform: scale(1);
  box-shadow: 0 2px 8px rgba(0,0,0,0.1);
  transition: transform 0.3s, box-shadow 0.3s;
}

.karta:hover {
  transform: scale(1.05);
  box-shadow: 0 8px 24px rgba(0,0,0,0.15);
}

4. transform — Lëviz, rrotullo, zmadho

transform të lejon të bësh gjëra vizuale pa ndryshuar layout-in. Ja funksionet kryesore:

5. @keyframes — Animacione me hapa

transition funksionon vetëm me :hover ose ndryshime klase. Për animacione që fillojnë vetë (pa hover), përdor @keyframes:

CSS 
/* Hapi 1: Krijo animacionin */
@keyframes pulso {
  0%   { transform: scale(1);   }
  50%  { transform: scale(1.1); }
  100% { transform: scale(1);   }
}

/* Hapi 2: Përdore tek elementi */
.butoni {
  animation: pulso 2s infinite;
}
Butoni pulson vetë — pa hover!
💡 Si funksionon?

@keyframes emri — krijon animacionin me hapa (0%, 50%, 100%).
animation: emri 2s infinite — e aplikon tek elementi: emri, kohëzgjatja, dhe pafundësisht.

6. Sintaksa e animation

Njësoj si transition, edhe animation ka disa pjesë:

CSS 
animation: emri  kohëzgjatja  easing  vonesa  përsëritja;

/* Shembuj: */
animation: pulso 2s infinite;
animation: hyr 0.5s ease-out;
animation: lëviz 1s ease-in-out 0.3s infinite;
Pjesa Çfarë bën Vlera të zakonshme
nameEmri i @keyframespulso, hyr, lëviz
durationSa zgjat 1 cikël0.5s, 1s, 2s
easingSi lëvizease, linear, ease-in-out
delaySa pret para fillimit0s, 0.3s, 1s
iteration-countSa herë përsëritet1, 3, infinite

7. Shembull — Fade In (shfaqje e ngadaltë)

Njëri nga efektet më të përdorshme — elementi shfaqet ngadalë kur hapet faqja:

CSS 
@keyframes fadeIn {
  from { opacity: 0;  transform: translateY(20px); }
  to   { opacity: 1;  transform: translateY(0);    }
}

.titulli {
  animation: fadeIn 0.6s ease-out;
}
Kliko "Rifillo" për të parë efektin fade-in
Mirë se erdhe! 🎉
Ky tekst u shfaq me fade-in
💡 from / to vs 0% / 100%

from = 0% (fillimi).
to = 100% (fundi).
Janë njësoj! Përdor cilën dëshiron. Por kur ke disa hapa (p.sh. 50%), duhen përqindjet.

8. transition vs animation — Kur cilën?

Dy mjete të ndryshme për qëllime të ndryshme:

transition animation
Aktivizohet nga diçka (hover, klik, klasë)Fillon vetë (ose me klasë)
Nga gjendja A → B (2 hapa)Disa hapa (0%, 25%, 50%, 100%)
Ideal për: hover, focus, ndryshim klaseIdeal për: loading, pulsim, shfaqje, lojëra
Nuk përsëritet (veç nëse hover prap)Mund të përsëritet (infinite)
💡 Rregulli i thjeshtë

Përdor transition për efekte hover (butona, karta, linqe).
Përdor animation kur dëshiron që diçka të lëvizë vetë, pa ndërveprim.
