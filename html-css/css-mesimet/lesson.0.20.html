Teksti dhe Tipografia: Si stilizojmë tekstin me CSS

Teksti është pjesa më e rëndësishme e çdo faqeje web. Me CSS mund të kontrollojmë fontin, madhësinë, peshën, drejtimin, hapësirën dhe shumë cilësi të tjera të tekstit.

Në këtë mësim do të mësojmë pronat kryesore për tipografinë në CSS.

1. font-family — Lloji i fontit

Prona font-family cakton cilin font përdor teksti. Gjithmonë jep disa alternativa në rast se fonti i parë nuk gjendet.

CSS 
body {
  font-family: "Nunito Sans", Arial, sans-serif;
}

.kodi {
  font-family: "Fira Code", monospace;
}
Familjet kryesore të fonteve
Arial (sans-serif) Pa vizë — modern, i pastër
Times New Roman (serif) Me vizë — klasik, formal
Courier New (monospace) Hapësirë e njëjtë — për kod
Këshillë

Gjithmonë përfundo listën me një font gjenerik (sans-serif, serif, ose monospace) si rrjetë sigurie.

2. font-size — Madhësia e tekstit

Kontrollon sa i madh duket teksti. Njësitë më të përdorura:

CSS 
h1 {
  font-size: 32px;     /* pikselë — madhësi fikse */
}

p {
  font-size: 1.125rem;  /* rem — relative ndaj root */
}

small {
  font-size: 14px;
}
Krahasim madhësish
12px — Tekst i vogël 16px — Madhësia bazë (default) 20px — Tekst mesatar 28px — Titull 40px — Titull i madh
px vs rem

px — madhësi fikse, nuk ndryshon.
rem — relative ndaj madhësisë bazë (zakonisht 16px). 1rem = 16px, 1.5rem = 24px.
Për projekte reale, rem rekomandohet sepse përshtatet me preferencat e përdoruesit.

3. font-weight — Pesha e tekstit

Kontrollon sa i trashë (bold) ose i hollë duket teksti.

CSS 
.normal { font-weight: 400; }   /* normal */
.gjysem { font-weight: 600; }   /* semi-bold */
.trashe { font-weight: bold; }  /* bold = 700 */
.extra  { font-weight: 800; }   /* extra-bold */
Preview
font-weight: 300 (light) font-weight: 400 (normal) font-weight: 600 (semi-bold) font-weight: 700 (bold) font-weight: 800 (extra-bold)

4. text-align — Drejtimi i tekstit

Kontrollon nëse teksti shfaqet majtas, në qendër, djathtas ose i shtrirë.

CSS 
.majtas  { text-align: left; }
.qender  { text-align: center; }
.djathtas { text-align: right; }
.shtri   { text-align: justify; }
Preview
left — Teksti shkon majtas (default)
center — Teksti në qendër
right — Teksti shkon djathtas
justify — Teksti shtrihet nga skaji në skaj si në gazeta

5. text-decoration — Dekorimi i tekstit

Shton ose heq vizat dekorative (underline, overline, line-through).

CSS 
.nenvize { text-decoration: underline; }
.kryqzo  { text-decoration: line-through; }
.pa-vize { text-decoration: none; }     /* heq vizën */
Preview
underline — nënvizë line-through — kryqëzim overline — vizë sipër none — pa dekorim
Përdorim i zakonshëm

text-decoration: none; përdoret shpesh për të hequr vizën nën linqet (<a>) që kanë underline si parazgjedhje.

6. line-height — Lartësia e rreshtit

Kontrollon hapësirën vertikale ndërmjet rreshtave të tekstit. Vlera ideale për lexueshmëri është 1.5 deri 1.8.

CSS 
p {
  font-size: 16px;
  line-height: 1.6;   /* 1.6 × 16px = 25.6px ndërmjet rreshtave */
}
Krahasim
line-height: 1.0 (shumë ngushtë)

Ky tekst ka hapësirë shumë të ngushtë ndërmjet rreshtave dhe është i vështirë për t'u lexuar kur ka shumë tekst.

line-height: 1.6 (ideale)

Ky tekst ka hapësirë të mirë ndërmjet rreshtave. Leximi është i rehatshëm dhe sytë nuk lodhen.

line-height: 2.5 (shumë e gjerë)

Ky tekst ka hapësirë shumë të madhe. Faqja duket e zbrazët dhe e gjatë.

7. letter-spacing dhe word-spacing

Kontrollojnë hapësirën ndërmjet shkronjave dhe fjalëve.

CSS 
.gjer {
  letter-spacing: 3px;   /* hapësirë ndërmjet shkronjave */
}

.ngusht {
  letter-spacing: -1px;  /* i ngushton */
}

.fjale-larg {
  word-spacing: 10px;    /* hapësirë ndërmjet fjalëve */
}
Preview
letter-spacing: 0px (normal) letter-spacing: 3px (i gjerë) letter-spacing: 6px (titull stili) word-spacing: 12px (fjalë larg)

8. text-transform — Shkronja të mëdha/të vogla

Ndryshon raportin e shkronjave pa e ndryshuar tekstin në HTML.

CSS 
.madhe    { text-transform: uppercase; }   /* TË GJITHA MADHE */
.vogel    { text-transform: lowercase; }   /* të gjitha vogla */
.kapitale { text-transform: capitalize; }  /* Fillimi Madh */
Preview
uppercase — mëso programimin lowercase — MËSO PROGRAMIMIN capitalize — mëso programimin

Kombinimi i pronave — Shembull real

Në projekte reale, kombinojmë disa prona së bashku për rezultate profesionale:

CSS 
h1 {
  font-family: "Nunito Sans", sans-serif;
  font-size: 36px;
  font-weight: 800;
  color: #7c3aed;
  text-align: center;
  letter-spacing: -0.5px;
}

p {
  font-family: "Nunito Sans", sans-serif;
  font-size: 16px;
  font-weight: 400;
  color: #94a3b8;
  line-height: 1.7;
}
Rezultati

Mirë se erdhe!

Kjo faqe përdor tipografi profesionale. Titulli ka font të trashë me ngjyrë vjollcë, ndërsa paragrafi ka font normal me ngjyrë gri të lehtë dhe hapësirë të mirë ndërmjet rreshtave.
