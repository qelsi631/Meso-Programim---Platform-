✨ Kursi i CSS

Mirë se vini në CSS Styling

Në këtë kurs do të mësoni si të stilizoni faqet HTML me ngjyra, spacing, layout dhe tipografi.

Çfarë është CSS?

CSS (Cascading Style Sheets) është gjuha që kontrollon pamjen e faqeve web: ngjyrat, madhësitë, distancat dhe pozicionimin e elementeve.

Nëse HTML është struktura, CSS është dizajni.

CSS në Website

CSS përdoret për të stilizuar elementet HTML dhe për të krijuar dizajne të bukura dhe funksionale.
Shembull me posht: Nje faqe vetem me HTML dhe nje faqe ne HTML + CSS.

Si shtohet CSS?

Egzistojne 3 menyra kryesore per te shtuar CSS ne HTML, dhe ne do ti mesojme nje nga nje.

Inline CSS

Inline CSS është mënyra më e thjeshtë për të stilizuar një element HTML duke përdorur atributin style direkt brenda tagut.
Ne kete raste kemi nje shembull se si shkruhet sintaksa per Inline CSS:

      
<p style="color: blue;">Ky eshte paragraf me ngjyre te kaltër</p>
Preview

Ky eshte paragraf me ngjyre te kaltër

Shpjegim
style="color: blue;"
color është property (vetia) e CSS-së,
ndërsa blue është value (vlera) që i jepet property-t.
Pra, property tregon se çfarë do të ndryshojmë (ngjyrën ne rastin tonë), ndërsa value tregon se çfarë ngjyre do të vendosim (blue).

Ky kod krijon një paragraf dhe përdor CSS brenda atributit style për ta stiluar tekstin.
