Display dhe Position: Si vendosen elementet në faqe

Tani që e njeh Box Model, hapi tjetër është të mësosh si vendosen dhe pozicionohen elementet në faqe. Dy pronat kryesore janë display (si sillet elementi me të tjerët) dhe position (ku vendoset në faqe).

Këto prona janë thelbësore për çdo layout (paraqitje) që do të ndërtosh.

1. display: block — Elementi zë gjithë rreshtin

Elementet block fillojnë në rresht të ri dhe zëjnë gjithë gjerësinë e disponueshme. Shembuj: <div>, <p>, <h1>–<h6>, <section>.

CSS 
.kutia {
  display: block;
  width: 200px;
  background: #7c3aed;
  padding: 12px;
  margin-bottom: 8px;
}

2. display: inline — Elementi rri në të njëjtin rresht

Elementet inline rrinë në rresht bashkë me tekstin. Nuk pranojnë width/height, dhe margin/padding vertikale nuk i lëvizin elementet e tjerë. Shembuj: <span>, <a>, <strong>.

CSS 
.etiketa {
  display: inline;
  background: #7c3aed;
  color: #fff;
  padding: 4px 10px;
  border-radius: 4px;
}
Inline — në rresht me tekstin

Ky është tekst normal dhe etiketa 1 rri në rresht bashkë me etiketa 2 tekstin tjetër.

3. display: inline-block — Kombinimi më i mirë

inline-block kombinon të dyja: rri në rresht si inline, por pranon width, height, margin, padding si block. Shumë i dobishëm për butona dhe karta.

CSS 
.buton {
  display: inline-block;
  width: 120px;
  padding: 10px;
  text-align: center;
  background: #7c3aed;
  color: #fff;
  border-radius: 6px;
}

4. display: none — Fshih elementin

display: none e fshin plotësisht elementin — nuk shihet dhe nuk zë hapësirë. Ndryshon nga visibility: hidden që e fshin por e mban hapësirën.

CSS 
/* Fshihet plotësisht */
.fshehur {
  display: none;
}

/* I padukshëm por zë hapësirë */
.i-padukshem {
  visibility: hidden;
}

Pjesa 2: Position — Pozicionimi i elementeve

Prona position kontollon si pozicionohet elementi në faqe. Bashkë me top, right, bottom, left caktojmë vendndodhjen e saktë.

5. position: static — Pozicioni normal (default)

Kjo është vlera e parazgjedhur. Elementi vendoset sipas rrjedhës normale të dokumentit. Pronat top/right/bottom/left nuk funksionojnë me static.

CSS 
.normale {
  position: static;  /* kjo është default */
}

6. position: relative — Lëviz nga pozicioni normal

Elementi qëndron në rrjedhën normale, por mund ta lëvizësh me top/right/bottom/left. Hapësira e tij origjinale mbetet e rezervuar.

CSS 
.levizur {
  position: relative;
  top: 20px;     /* lëviz 20px poshtë */
  left: 30px;    /* lëviz 30px djathtas */
}

Kur përdoret relative?

Zakonisht si pikë referimi për fëmijët me position: absolute. Gjithashtu për lëvizje të vogla vizuale pa ndryshuar layout-in.

7. position: absolute — Vendoset sipas prindit

Elementi del nga rrjedha normale dhe pozicionohet sipas prindit më të afërt që ka position: relative (ose sipas faqes nëse asnjë prind nuk ka). Nuk zë hapësirë në rrjedhë.

CSS 
.prindi {
  position: relative;  /* pikë referimi */
  width: 300px;
  height: 200px;
}

.femija {
  position: absolute;
  top: 10px;
  right: 10px;
}

Gjithmonë vendos position: relative tek prindi kur përdor absolute tek fëmija. Pa këtë, elementi pozicionohet sipas gjithë faqes!

8. position: fixed — Qëndron fiks në ekran

Elementi qëndron në të njëjtin vend edhe kur përdoruesi scroll-on. Pozicionohet sipas dritares (viewport), jo dokumentit.

CSS 
/* Navbar që qëndron gjithmonë sipër */
.navbar {
  position: fixed;
  top: 0;
  left: 0;
  width: 100%;
  background: #1a1a2e;
  padding: 12px 20px;
}

/* Buton "Kthehu sipër" në fund-djathtas */
.scroll-top {
  position: fixed;
  bottom: 20px;
  right: 20px;
}

9. position: sticky — Ngjitet kur scroll-on

Sticky është kombinim i relative dhe fixed: elementi sillet normalisht derisa përdoruesi scroll-on te ai, pastaj "ngjitet" në pozicionin e caktuar.

CSS 
.titulli {
  position: sticky;
  top: 0;             /* ngjitet kur arrin sipër */
  background: #1a1a2e;
  padding: 10px;
}
Kur përdoret sticky?

Për titujt e seksioneve që ngjiten kur scroll-on, tabela me header-ë të fiksuar, ose sidebar-ë që ndjekin scroll-in. Kijo ta provon shpesh në faqet moderne!

10. z-index — Cili element del sipër

Kur elementet mbishtrihen, z-index vendos cilin sheh përdoruesi sipër. Numri më i madh = më sipër. Funksionon vetëm me elementet që kanë position (jo static).

CSS 
.kutia-1 { z-index: 1; }
.kutia-2 { z-index: 10; }  /* kjo del sipër */
.kutia-3 { z-index: 5; }
