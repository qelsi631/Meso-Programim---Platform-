Ngjyrat në CSS: Si shkruhen dhe përdoren

Ngjyrat janë njëra nga pjesët më të rëndësishme të CSS — ato e bëjnë faqen tërheqëse dhe profesionale. CSS ofron disa mënyra për të shkruar ngjyrat, dhe në këtë mësim do t'i mësojmë të gjitha.

Do të mësojmë: Named Colors, Hex, RGB, RGBA dhe HSL.

1. Ngjyrat me Emër (Named Colors)

Mënyra më e thjeshtë — shkruaj emrin e ngjyrës drejtpërdrejt në anglisht. CSS njeh 140+ ngjyra me emra.

CSS 
h1 {
  color: tomato;
}

p {
  color: steelblue;
}

div {
  background-color: gold;
}
Disa ngjyra popullore
tomato steelblue gold coral darkslategray orchid limegreen hotpink
Kur përdoren?

Named colors janë të mira për testime të shpejta dhe prototipe. Në projekte reale, zakonisht përdoren Hex ose RGB për kontroll më të saktë.

2. Ngjyrat Hex (#RRGGBB)

Formati Hex (hexadecimal) është mënyra më e përdorur në web. Fillon me # dhe ka 6 shifra që përfaqësojnë ngjyrën me vlera të Kuqes, Gjelbërtit dhe Bluas.

CSS 
.kutia {
  background-color: #7c3aed;   /* vjollcë */
  color: #ffffff;            /* e bardhë */
  border: 2px solid #ff6600;  /* portokalli */
}
Si funksionon Hex?
#RRGGBB

RR = sasia e kuqes (00–FF)
GG = sasia e gjelbërtit (00–FF)
BB = sasia e bluas (00–FF)

00 = asnjë nga ajo ngjyrë, FF = maksimumi.
#000000 = e zezë, #ffffff = e bardhë.

Shembuj Hex

Hex i shkurtuar (3 shifra)

Kur çiftet janë të njëjta, mund ta shkurtosh:

CSS 
/* Këto janë identike: */
color: #ff0000;  /* e plotë */
color: #f00;     /* e shkurtuar */

color: #ffffff;  /* e plotë */
color: #fff;     /* e shkurtuar */

3. Ngjyrat RGB

Formati RGB përdor numra nga 0 deri 255 për çdo kanal ngjyrash: Red (kuq), Green (gjelbërt), Blue (blu).

CSS 
.titulli {
  color: rgb(124, 58, 237);          /* vjollcë */
}

.sfond {
  background-color: rgb(255, 102, 0);   /* portokalli */
}
Sintaksa
rgb(kuq, gjelbërt, blu)

Çdo vlerë shkon nga 0 (asnjë) deri 255 (maksimum).
rgb(0, 0, 0) = e zezë, rgb(255, 255, 255) = e bardhë.

4. RGBA — Ngjyra me Transparencë

RGBA është si RGB, por me një vlerë të katërt: Alpha (A) — niveli i transparencës. Kjo është shumë e dobishme për efekte vizuale.

CSS 
.mbivendosje {
  background-color: rgba(0, 0, 0, 0.5);  /* e zezë 50% transparente */
}

.kartela {
  background-color: rgba(124, 58, 237, 0.15);  /* vjollcë shumë e lehtë */
}
Vlera Alpha
rgba(R, G, B, A)

A (Alpha) shkon nga 0 (plotësisht transparente) deri 1 (plotësisht e dukshme).
0.5 = gjysëm transparente, 0.1 = pothuajse e padukshme.

5. HSL — Ngjyra sipas Nuancës

HSL (Hue, Saturation, Lightness) është mënyra më intuitive — zgjedh nuancën, sa e fortë është, dhe sa e ndritshme.

CSS 
.butoni {
  background: hsl(262, 83%, 58%);   /* vjollcë */
  color: hsl(0, 0%, 100%);       /* e bardhë */
}
Si funksionon HSL?
hsl(nuanca, fortësia%, ndriçimi%)

H (Hue) = nuanca e ngjyrës në rreth (0°–360°):
0° = e kuqe, 120° = e gjelbërt, 240° = blu, 360° = e kuqe prapë

S (Saturation) = fortësia e ngjyrës (0% = gri, 100% = e fortë)

L (Lightness) = ndriçimi (0% = e zezë, 50% = normale, 100% = e bardhë)

color vs background-color

Dy pronat kryesore që përdorin ngjyra:

  • color — ndryshon ngjyrën e tekstit.
  • background-color — ndryshon ngjyrën e sfondit të elementit.
CSS 
.butoni {
  color: #ffffff;              /* teksti i bardhë */
  background-color: #7c3aed;   /* sfondi vjollcë */
}

Përmbledhje e shpejtë

  • Named Colors — të thjeshta por të limituara (140 ngjyra).
  • Hex (#rrggbb) — standardi më i përdorur, kompakte.
  • RGB — si Hex por me numra 0–255.
  • RGBA — si RGB por me transparencë (alpha 0–1).
  • HSL — intuitive, e mirë për variancione ngjyrash.
  • color = ngjyra e tekstit, background-color = ngjyra e sfondit.
