Shtimi i CSS në HTML: Internal dhe External

Ne mesimin paraprak mesuam si shtohet CSS në HTML duke perdorur style="" brenda elementeve HTML.
Kjo metode e perdorimit te CSS do te na merrte shume kohe dhe do te bente kodin te vështirë për t'u menaxhuar.
Kur punojme ne projekte reale, perdorimi i tepert i Inline CSS do te krijonte organizim te dobet dhe te nderlikuar, prandaj ne do te mesojme dy menyra me te perdorura per te shtuar CSS ne HTML: Internal dhe External.

Internal CSS

Internal CSS shkruhet brenda tags <style> në pjesën <head> të dokumentit HTML. Kjo mënyrë është e përshtatshme për një faqe të vetme.

Si funksionon? Shfletuesi e lexon kodin brenda <style> dhe i aplikon rregullat për elementet përkatëse në të njëjtën faqe.

HTML 
<!DOCTYPE html>
<html lang="sq">
<head>
  <meta charset="UTF-8">
  <title>Shembull Internal CSS</title>
  <style>
    h1 {
      color: #7c3aed;
      text-align: center;
      margin-bottom: 10px;
    }

    p {
      font-size: 18px;
      color: #374151;
      line-height: 1.6;
      text-align: center;
    }
  </style>
</head>
<body>
  <h1>Mire se erdhe!</h1>
  <p>Ky tekst po stilizohet me Internal CSS.</p>
</body>
</html>
Kur përdoret Internal CSS?

Internal CSS është i mirë për faqe të vetme ose kur po teston diçka shpejt. Por nëse ke shumë faqe, do të duhet ta kopjosh kodin kudo — prandaj për projekte të vërteta, përdor External CSS.

External CSS

External CSS ruhet në një file të veçantë .css dhe lidhet me HTML përmes tags <link>. Kjo është metoda më e mirë për projekte reale sepse e mban kodin të organizuar.

Si funksionon? HTML lidh file-in style.css me <link>, dhe i njëjti file CSS mund të përdoret nga shumë faqe njëkohësisht.

HTML + CSS 
<!-- index.html -->
<!DOCTYPE html>
<html lang="sq">
<head>
  <meta charset="UTF-8">
  <title>Shembull External CSS</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <h1>Titulli i faqes</h1>
  <button>Kliko</button>
</body>
</html>

/* style.css */
h1 {
  color: #16a34a;
}

button {
  background: #16a34a;
  color: white;
  border: none;
  padding: 10px 16px;
  border-radius: 8px;
}
Pse External CSS?

Me External CSS, shkruan stilin një herë në file-in .css dhe e lidh me sa faqe të duash. Kështu ndryshon dizajnin nga një vend i vetëm pa kopjuar asgjë. Kjo është mënyra standarde në projekte reale.

Përmbledhje e shpejtë

  • Internal CSS = për faqe të vetme dhe testime të shpejta.
  • External CSS = zgjedhja kryesore për projekte të vërteta.
  • Nëse projekti rritet, kalo gjithmonë te External CSS për organizim më të mirë.
