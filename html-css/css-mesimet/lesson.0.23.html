CSS Flexbox: Layout-i modern dhe fleksibël

Flexbox është mënyra më e lehtë dhe më e fuqishme për të rreshtuar elemente në rreshta ose kolona. Me vetëm disa prona, mund të ndërtosh layout-e profesionale pa përdorur float ose pozicionim absolut.

Në këtë mësim do të mësosh gjithçka që të nevojitet për Flexbox: si aktivizohet, si drejtohet, si rreshtohen dhe si shpërndahen elementet.

1. display: flex — Aktivizo Flexbox

Për të përdorur Flexbox, thjesht vendos display: flex tek kontejneri (prindi). Fëmijët e tij bëhen automatikisht flex items dhe rreshtohen në një rresht.

CSS 
.kontejner {
  display: flex;
}

2. flex-direction — Drejtimi i elementeve

Kjo pronë vendos drejtimin e rreshtimit. Default është row (horizontal). Mund ta ndryshosh në column (vertikal) ose edhe t'i kthesh mbrapsht.

CSS 
.rresht {
  display: flex;
  flex-direction: row;          /* ← default: majtas→djathtas */
}

.kolone {
  display: flex;
  flex-direction: column;       /* sipër→poshtë */
}

.rresht-mbrapsht {
  display: flex;
  flex-direction: row-reverse;  /* djathtas→majtas */
}

5. Qendërzim perfekt — Truku i artë i Flexbox

Problemi më i famshëm i CSS: si ta qendërzosh një element horizontalisht dhe vertikalisht? Me Flexbox, mjaftojnë vetëm 3 rreshta:

CSS 
.qenderzim {
  display: flex;
  justify-content: center;  /* ← horizontal */
  align-items: center;      /* ↕ vertikal */
  height: 200px;
}
Qendërzim perfekt!
Jam në qendër! 🎯
💡 Mësoje këtë përmendësh!

display: flex + justify-content: center + align-items: center = qendërzim perfekt. Kjo do të përdoret shumë shpesh në projekte.

6. gap — Hapësira ndërmjet elementeve

Prona gap shton hapësirë ndërmjet flex items pa përdorur margin. Shumë më e pastër dhe e lehtë!

CSS 
.kontejner {
  display: flex;
  gap: 16px;           /* hapësirë e barabartë */
}

/* Ose vlera të ndryshme për rreshta/kolona */
.kontejner-2 {
  display: flex;
  gap: 10px 20px;     /* rreshta 10px, kolona 20px */
}

7. flex-wrap — Mbështjellja në rreshta të rinj

Normalisht, flex items qëndrojnë në një rresht edhe nëse nuk ka vend. Me flex-wrap: wrap, elementet kalojnë në rreshtin tjetër kur mbushet hapësira.

CSS 
.kontejner {
  display: flex;
  flex-wrap: wrap;     /* kalo në rresht të ri */
  gap: 12px;
}

.item {
  width: 100px;
}

8. Shembull praktik — Navbar me Flexbox

Le të ndërtojmë një navbar profesionale. Logo në të majtë, linqet në të djathtë, të gjitha të qendërzuara vertikalisht:

HTML + CSS 
.navbar {
  display: flex;
  justify-content: space-between;
  align-items: center;
  padding: 12px 24px;
  background: #1a1a2e;
}

.nav-linqet {
  display: flex;
  gap: 20px;
}

9. Shembull praktik — Layout me karta

Tre karta njëra pranë tjetrës, që adaptohen kur ekrani zvogëlohet:

CSS 
.kartat {
  display: flex;
  flex-wrap: wrap;
  gap: 16px;
}

.karta {
  flex: 1 1 250px;     /* rritet, zvogëlohet, min 250px */
  padding: 20px;
  background: #262637;
  border-radius: 10px;
}
Karta responsive me flex-wrap
