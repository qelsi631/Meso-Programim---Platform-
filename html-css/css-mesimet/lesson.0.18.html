Selektorët CSS: Element, Class dhe ID

Në mësimet e mëparshme mësuam si të shtojmë CSS në HTML (Inline, Internal, External). Tani do të mësojmë si i zgjedhim elementet që dëshirojmë t'i stilizojmë. Këta quhen selektorë.

Selektorët janë baza e CSS — pa ta njohur selektorin e duhur, CSS nuk di cilën pjesë të faqes ta ndryshojë.

1. Selektori i Elementit

Selektori i elementit zgjedh të gjithë elementet e atij lloji në faqe. Shkruhet thjesht me emrin e tagut HTML.

Sintaksa:

CSS 
p {
  color: #2563eb;
  font-size: 18px;
}

h1 {
  color: #7c3aed;
  text-align: center;
}
Shpjegim

p — zgjedh të gjithë paragrafët në faqe.
h1 — zgjedh të gjithë titujt h1 në faqe.

Kujdes: Selektori i elementit ndikon çdo element të atij lloji. Nëse ke 5 paragrafe, të 5-tët do të jenë blu.

2. Selektori i Klasës (.class)

Selektori i klasës zgjedh elementet që kanë një atribut class të caktuar. Shkruhet me . (pikë) para emrit të klasës.

Klasat janë të ripërdorshme — mund t'ia shtosh shumë elementeve njëkohësisht.

HTML 
<p class="theksuar">Ky tekst është i veçantë.</p>
<p>Ky tekst nuk ka klasë.</p>
<p class="theksuar">Edhe ky tekst është i veçantë!</p>
CSS 
.theksuar {
  color: #ff6600;
  font-weight: bold;
  background-color: #fff3e0;
  padding: 8px 14px;
  border-radius: 6px;
}
Preview

Shpjegim

.theksuar — pika e bën CSS të kuptojë që po kërkojmë elementet me class="theksuar".

Vetëm paragrafët me klasën theksuar do të stilizohen. Paragrafi pa klasë mbetet si parazgjedhje.

Shumë klasa në një element

Një element mund të ketë shumë klasa, të ndara me hapësirë:

HTML + CSS 
<!-- HTML -->
<p class="tekst-madh ngjyre-kuqe">Tekst i madh dhe i kuq</p>

/* CSS */
.tekst-madh {
  font-size: 24px;
}

.ngjyre-kuqe {
  color: #dc2626;
}

3. Selektori i ID-së (#id)

Selektori i ID-së zgjedh një element unik që ka atributin id. Shkruhet me # para emrit të ID-së.

Rregull e rëndësishme: Çdo ID duhet të jetë unik — vetëm një element në faqe mund ta ketë atë ID.

HTML 
<h1 id="titulli-kryesor">Faqja Kryesore</h1>
<p id="hyrje">Mirë se erdhe në faqen tonë!</p>
CSS 
#titulli-kryesor {
  color: #16a34a;
  font-size: 32px;
  text-align: center;
  border-bottom: 3px solid #16a34a;
  padding-bottom: 10px;
}

#hyrje {
  font-style: italic;
  color: #6b7280;
  text-align: center;
}
Preview

Shpjegim

#titulli-kryesor — simboli # i tregon CSS që po kërkojmë elementin me id="titulli-kryesor".

ID përdoret kur dëshiron të stilizosh vetëm një element specifik, jo shumë si klasa.

Krahasimi: Element vs Class vs ID

Selektori Sintaksa Zgjedh Ripërdorim
Element p { } Të gjithë elementet e atij lloji Automatik (çdo element)
Class .emri { } Elementet me atë klasë Po — shumëfish
ID #emri { } Vetëm një element unik Jo — vetëm një herë

Kur përdoret secili?

  • Element: Kur dëshiron të stilizosh të gjithë elementet e njëjtë (p.sh. çdo paragraf, çdo titull).
  • Class: Kur dëshiron të stilizosh disa elemente — jo të gjithë, por ato që zgjedh ti. Kjo është mënyra më e përdorur në CSS.
  • ID: Kur dëshiron të stilizosh vetëm një element specifik. Përdoret rrallë për stilim — më shumë për JavaScript.

Prioriteti i Selektorëve

Kur shumë selektorë përpiqen të stilizojnë të njëjtin element, CSS ka një rregull: kush fiton?

1. #id — prioriteti më i lartë (specifik)
2. .class — prioriteti mesatar
3. element — prioriteti më i ulët
Shembull prioriteti 
<!-- HTML -->
<p id="special" class="theksuar">Cila ngjyrë fiton?</p>

/* CSS */
p { color: blue; }        /* element — humbet */
.theksuar { color: orange; }  /* class — humbet */
#special { color: green; }   /* ID — FITON! ✅ */
Rezultati

Cila ngjyrë fiton? → E gjelbër (ID fiton!)

Përmbledhje e shpejtë

  • Selektori i elementit (p, h1, div) — zgjedh të gjithë elementet e atij lloji.
  • Selektori i klasës (.emri) — zgjedh vetëm elementet me atë klasë. Më i përdoruri!
  • Selektori i ID-së (#emri) — zgjedh vetëm një element unik.
  • Prioriteti: ID > Class > Element.
  • Klasa është mënyra më e mirë për stilim të përditshëm.
