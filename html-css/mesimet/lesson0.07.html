Linket në HTML

Mëso si të krijosh linke me tag-un <a> për navigim në faqe dhe jashtë saj.

🔗

Çfarë është tag-u <a>?

Linket gjenden pothuajse në të gjitha faqet web. Linket u lejojnë përdoruesve të klikojnë dhe të kalojnë nga një faqe në tjetrën.

Tagu <a> (anchor) përdoret për të krijuar linke. Atributi më i rëndësishëm është href, që tregon ku do të shkojë linku.

Atributet kryesore

  • href – adresa e destinacionit
  • target – hapja në tab të ri (p.sh. _blank)
  • rel – siguria kur hapet në tab të ri

Link i thjeshtë (absolute URL)

Ky është link drejt një faqeje tjetër në internet.

HTML 
<a href="https://linku.com">Vizito Linku.com</a>

Shënim: Një link nuk duhet patjetër të jetë tekst. Një link mund të jetë një imazh ose çdo element tjetër HTML!

Çdo element bëhet link thjesht duke e futur brenda tagut <a> me atributin href.

<a href="https://linku.com">Vizito Linku.com</a>

Anatomia e linkut

Shënim: Një link nuk duhet patjetër të jetë tekst. Një link mund të jetë një imazh ose çdo element tjetër HTML!

Çdo element bëhet link thjesht duke e futur brenda tagut <a> me atributin href.

HTML 
<a href="https://linku.com">
  <img src="https://via.placeholder.com/150" alt="Kliko për të vizituar Linku.com">
</a>

Në mësimin tjetër do të mësojmë si të shtojmë audio dhe video në HTML.
