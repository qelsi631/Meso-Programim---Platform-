Listat në HTML

Mëso si të krijosh lista të rregullta me <ul>, <ol> dhe <li>.

📋

Çfarë janë listat?

Listat ndihmojnë të paraqesësh informacione në mënyrë të qartë dhe të strukturuar. Përdoren shumë në menu, detyra dhe përshkrime.

Elementet kryesore

  • <ul> – listë me pika (unordered)
  • <ol> – listë me numra (ordered)
  • <li> – çdo element i listës

Listë e thjeshtë me pika

(Unordered List) në HTML përdoret për të krijuar lista të parenditura, pra lista ku elementet nuk kanë rend numerik dhe zakonisht shfaqen me pika (•). Çdo element i listës vendoset brenda tagut <li>.

HTML 
<ul>
  <li>HTML</li>
  <li>CSS</li>
  <li>JavaScript</li>
</ul>

Listë e numëruar

(Ordered List) në HTML përdoret për të krijuar lista të renditura, ku elementet shfaqen sipas një rendi të caktuar, zakonisht me numra, shkronja ose numra romakë. Çdo element i listës vendoset brenda tagut <li>.

  3. JavaScript
