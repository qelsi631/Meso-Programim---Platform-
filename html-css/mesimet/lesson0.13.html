Input Types në HTML

Këtu do të kuptosh qartë çdo lloj input-i dhe kur përdoret.

Çfarë është type?

Atributi type i tregon browser-it çfarë lloj të dhënash priten. Kjo e bën formularin më të lehtë për përdoruesin dhe më të saktë për verifikim.

HTML 
<input type="text" name="emri">
<input type="email" name="email">
<input type="password" name="fjalekalimi">

Input type="text"

type="text" krijon një fushë teksti me një rresht.

Preview:

HTML 
<form>
  <label for="fname">First name:</label><br>
  <input type="text" id="fname" name="fname"><br>
  <label for="lname">Last name:</label><br>
  <input type="text" id="lname" name="lname">
</form>

Input type="password"

type="password" fsheh karakteret kur përdoruesi shkruan.

Preview:

HTML 
<form>
  <label for="pass">Password:</label><br>
  <input type="password" id="pass" name="pass">
</form>

Input type="email"

type="email" kërkon format të vlefshëm email-i.

Preview:

HTML 
<form>
  <label for="email">Email:</label><br>
  <input type="email" id="email" name="email">
</form>

Input type="number"

type="number" pranon vetëm numra.

Preview:

HTML 
<form>
  <label for="age">Mosha:</label><br>
  <input type="number" id="age" name="age" min="1" max="120">
</form>

Input type="radio"

type="radio" lejon vetëm një zgjedhje në grup (i njëjti name).

Preview:

Gjinia:
HTML 
<form>
  <p>Gjinia:</p>
  <input type="radio" id="f" name="gjinia" value="F">
  <label for="f">F</label><br>
  <input type="radio" id="m" name="gjinia" value="M">
  <label for="m">M</label>
</form>

Input type="checkbox"

type="checkbox" lejon më shumë se një zgjedhje.

Preview:

HTML 
<form>
  <input type="checkbox" id="sport" name="hobi" value="sport">
  <label for="sport">Sport</label><br>
  <input type="checkbox" id="muzike" name="hobi" value="muzike">
  <label for="muzike">Muzikë</label>
</form>

Input type="button"

type="button" krijon buton të zakonshëm (përdoret shpesh me JavaScript).

Preview:

HTML 
<form>
  <input type="button" value="Kliko">
</form>

Input type="submit"

type="submit" dërgon të dhënat e formularit.

Preview:

HTML 
<form>
  <label for="email">Email:</label><br>
  <input type="email" id="email" name="email"><br>
  <input type="submit" value="Dërgo">
</form>
